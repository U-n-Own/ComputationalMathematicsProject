 \section{Problem Statement}
 \begin{framed}
 (P) is a sparse linear system of the form:
 \[
 \begin{bmatrix} \label{eq:1}
D & E^T\\
E & 0
\end{bmatrix}
\begin{bmatrix}
x\\y
\end{bmatrix}
=
\begin{bmatrix}
b\\c
\end{bmatrix}
 \]
 where $D\in\mathbb{R}^{m\times m}$ is a diagonal positive definite matrix (i.e., $D = \operatorname{diag}( D ) > 0$
) and $E\in\mathbb{R}^{(n-1)\times m}$ is obtained by removing the last row from the node-arc incidence matrix of a given connected directed graph. These problems arise as the KKT system of the convex quadratic separable Min-Cost Flow Problem, hence you can look, e.g., \href{https://commalab.di.unipi.it/datasets/mcf}{here} for ways to generate meaningful instances of the problem.\medskip
\begin{itemize}
 \item 
(A1) is GMRES, and you must solve the internal problems $\min \bigl\| H_n y - \|b\| e_1 \bigr\|$
 by updating the QR factorization of $H_n$
 at each step: given the QR factorization of $H_{n-1}$
 computed at the previous step, apply one more orthogonal transformation to compute that of $H_n$.
\item (A2)is the same GMRES, but using the so-called \emph{Schur complement preconditioner}
$$P = \begin{bmatrix}
     D & 0\\
     E & S
    \end{bmatrix}$$
    where $S$
 is either $S=ED^{-1}E^T$
 or a sparse approximation of it (to obtain it, for instance, replace the smallest off-diagonal entries of $S$
 with zeros).

\end{itemize}
No off-the-shelf solvers allowed.

 \end{framed}

 \section{GMRES}
 
GMRES is an iterative method for computing an approximation of the solution to the linear system $Ax = y$. It accomplishes such approximation by computing:
 \[\min_{x \in K_n(A, y)} \|Ax - y\|\]
 i.e. by finding the minimum $x$ within the \emph{Krylov Space} $K_n(A, y)$ such that the norm of the residual $Ax - y$ is minimized.
 \subsection{Background: Krylov Spaces and Arnoldi} 
 Given a non-necessarily-symmetric matrix (although in our case it is) $A \in \rmatr mm$, a vector $y \in \rvect m$, and a natural number $n\leq m$:
 \[K_n(A, y) = \spann (y, Ay, A^2y, \hdots, A^{n-1}y).\]
 We can obtain a good basis for this vector space by using the Arnoldi Algorithm:
 \[\arnoldi(A, y, n) =: Q_n, \hess_n\]
 Where:
 \begin{itemize}
  \item $Q_n \in \rmatr nm$ is the matrix $(q_1 \mid \hdots \mid q_n)$ of vectors in the basis;
  \item $\hess_n \in \rmatr {n+1} {n}$ is a matrix such that:
  \begin{enumerate}
   \item 
  \[\underbar H_n = \begin{bmatrix}
                     H_n\\
                     ...
                    \end{bmatrix}
\]
where $H_n \in \rmatr nn$ is s.t. $H_n = Q_n ^T A Q_n$, and can therefore be seen as $A$ in the Krylov subspace.
\item
  \begin{equation}
AQ_n = Q_{n+1} \hess_n \label{arnoldi_eq}
  \end{equation}
  \end{enumerate}

 \end{itemize}
 
 \begin{remark} \label{q1} The first vector of the basis generated by $\arnoldi(A, y, n)$ is $\dfrac y {\|y\|}$.
 \end{remark}

 \subsection{Simplifying the minimum problem}
 We can simplify the minimum problem to: $$\min_{z \in \reals^{n+1}} \|\hess_n z - e_1\|y\|\|$$
 \begin{proof}
 \begin{align}
  \min_{x \in K_n(A, y)} \|A x - y\| &= \min_{z \in \reals^{n+1}} \|A Q_n z - y\| \tag{$q_i$s form basis of $K_n(A, y)$}\\
  &= \min_{z \in \reals^{n+1}} \|Q_{n+1}\hess_n z - y\| \tag{by \eqref {arnoldi_eq}}\\
  &= \min_{z \in \reals^{n+1}} \|Q_{n+1}^T(Q_{n+1}\hess_n z - y)\| \tag{$Q_{n+1}^T$ orthogonal}\\
  &= \min_{z \in \reals^{n+1}} \|\hess_n z - Q_{n+1}^T y)\| \tag{$Q_{n+1}$ orthogonal}\\
  &= \min_{z \in \reals^{n+1}} \|\hess_n z - Q_{n+1}^T q_1 \|y\|\| \tag{by Remark \ref{q1}}\\
  &= \min_{z \in \reals^{n+1}} \|\hess_n z - e_1\|y\|\| \tag{$Q_{n+1}^T$ orthogonal}
 \end{align}

 \end{proof}

 \subsection{Lanczos}
 
 Since the input matrix $A$ is symmetric, we can use the Lanczos Algorithm to iteratively construct the orthonormal basis for the Krylov space. In particular, the $H_n$ matrix resulting from such algorithm will by symmetric and tridiagonal:
 \[H_n = \begin{bmatrix}
    \alpha_1 & \beta_1\\
    \beta_1 & \alpha_2 & \beta_2\\
    &\beta_2 & \alpha_3 & \ddots\\
    &&\ddots & \ddots & \beta_{m-2}\\
    &&&\beta_{m-2} &\alpha_{m-1}& \beta_{m-1}\\
    &&&& \beta_{m-1} & \alpha_m
   \end{bmatrix}
\]
This allows us to perform the computations without storing the whole matrix, but only the diagonal and subdiagonal. The Julia implementation of the algorithm is as follows: \sidenote{\color{red}TODO: Write this as pseudocode}

\begin{lstlisting}
function Lanczos(A::SparseMatrixCSC, y::SparseVector, n::Int)
    
    alpha = zeros(1,n)      # diagonal of H
    beta = zeros(1,n)       # subdiagonal of H (= superdiagonal of H because symmetric)
    
    L = zeros(size(A)[1], n)    # Lanczos Basis
    
    # base case
    
    q = y / norm(y)
    L[:, 1] = q
    w = A * q
    alpha[1] = w' * q
    w = w - alpha[1] * q
    beta[1] = norm(w)
    # inductive case
    
    for j in 2:n
        if j % 500 == 0
            println(j, "-th Lanczos iteration")
        end
        if beta[j-1] < 1e-13
            println("Breakdown");
            return
        end
        q = w / beta[j-1]
        L[:, j] = q
        
        w = A * q
        alpha[j] = w' * q
        w = w - alpha[j] * q - beta[j-1] * L[:, j-1]
        beta[j] = norm(w)
        
    end 
    
    return (L, alpha, beta)

end
\end{lstlisting}

\subsection{Lanczos + QR}
A trivial way to implement GMRES would be:
\begin{itemize}
 \item Use Lanczos to obtain a basis for the Krylov space
 \item Compute the QR factorization of $\hess_n$
 \item Use the factorization to easily solve the linear system arising from the minimum problem.
\end{itemize}
However, the requested version should compute the QR factorization during the Lanczos iteration.

\subsubsection{Extending the QR decomposition}
Assume we have $\underbar H_{n-1} = Q_{old}R_{old}$. The matrix $\underbar H_n$ will be computed using a Lanczos iteration, obtaining:
\[\underbar H_n = \left[\begin{array}{ c | c }
    \underbar H_{n-1} & \begin{matrix}
           0\\
           \vdots\\
           0\\
           \beta_{n-1}\\
           \alpha_n\\
          \end{matrix}
 \\
    \hline
    0 \quad\hdots\quad 0 & \beta_n
  \end{array}\right]
\]
We want to find two matrices $Q$, $R$ such that:
\begin{itemize}
 \item $Q\in \rmatr{(n+1)}{(n+1)}$ is orthogonal
 \item $R \in \rmatr{(n+1)}{n}$ is upper triangular
 \item $\underbar H_n = QR$, i.e. $Q^T \underbar H_n = R$
\end{itemize}
First off, to obtain a $Q$ matrix of the requested shape that is orthogonal, we could consider:
\[Q_{old}' = \left[\begin{array}{ c | c }
    Q_{old} & \begin{matrix}
           0\\
           \vdots\\
           0
          \end{matrix}
 \\
    \hline
    0 \quad\hdots\quad 0 & 1
  \end{array}\right]
\]
This takes us close to the solution, but not quite there; in fact the product $Q'^T_{old} \underbar H_n$ is \emph{almost} triangular:
\[Q'^T_{old} \underbar H_n = \left[\begin{array}{ c | c }
    R_{old} & 
           Q'^T_{old}\begin{bmatrix}
            0\\
            \vdots\\
            0\\
            \beta_{n-1}\\
            \alpha_n
           \end{bmatrix}
 \\
    \hline
    0 \quad\hdots\quad 0 & \beta_n
  \end{array}\right]
\]
Recall that $R_{old}$ is an $n \times (n-1)$ upper triangular matrix, hence it has a row of zeros at the bottom. To make this matrix triangular, we should have a zero in place of the $\beta_n$. We can get rid of such zero by performing a Householder reflection on the bottom two elements of the final column. Let these be:
\[x = \begin{bmatrix}
       a \\ \beta_n
      \end{bmatrix}
\quad\quad \mapsto \quad\quad y = \begin{bmatrix}
       \|x\| \\ 0
      \end{bmatrix}\] 
  As seen in class, the transformation we need is a reflection w.r.t $v = x - y$:
  \[H_{refl} = I - \dfrac{2 vv^T}{\|v\|^2}\]
  In order for the reflection to only act on the two bottom elements of the final row, we extend it as follows, obtaining another orthogonal transformation:
  \[O = \left[\begin{array}{ c | c }
    I & \begin{matrix}
         0&0\\
         \vdots &\vdots \\
         0&0
        \end{matrix}

 \\
    \hline
    \begin{matrix}
         0 \hdots 0\\0 \hdots 0
        \end{matrix} & H_{refl}
  \end{array}\right]\]
  The matrix we obtain as $OQ_{old}'^T\underbar H_n$ is triangular.
  
  \paragraph{Constructing the $R$ Matrix}
  \begin{itemize}
   \item Get old $R$;
   \item Compute:
   \[Q'^T_{old}[
            0,
            \hdots,
            0,
            \beta_{n-1},
            \alpha_n]^T= ([
            0,
            \hdots,
            0,
            \beta_{n-1},
            \alpha_n]Q'_{old})^T\]
  Let $q_1 ... q_n$ be the columns of $Q'_{old}$. (\sidenote{\color{red} Too many $Q$s: TODO rename Lanczos basis vector to $b_i$?}) The result is:
  \[\sum_i \beta_{n-1} q_{i, n-1} + \alpha_{n} q_{i, n}\]
  This can be rewritten, letting $r_1...r_n$ be the rows of $Q'_{old}$, as:
  \[\beta_{n-1}r_{n-1} + \alpha_n r_{n}\]
  \item Perform the $O$ transformation to obtain $R$.
  \end{itemize}

  \paragraph{Constructing the $Q$ matrix}
  \begin{itemize}
   \item Get old $Q$;
   \item Construct $Q_{old}'$ by adding the extra row and column;
   \item Compute $Q = (O Q'^T_{old})^T$. 
   
  \end{itemize}
  
  Altenatively we can calculate the new Q as follows:
  \[Q = O^T Q'_{old} = OQ_{old}\]
  By the symmetry of $O$, which is guaranteed by the symmetry of $H_{refl}$. Computationally, we only need to update the last two columns of $Q$, so we need not construct $O$ explicitly. The following Julia snippet shows such computation \sidenote{\color{red} TODO write pseudocode instead}

\begin{lstlisting}
  Q[j+1, j+1] = 1.0

  newcols = zeros(j+1, 2)
              
  for i in 1:j+1
    # Compute Q_old * O without constructing O
    # Can compute Q_old * O instead of Q_old * O' because O is sym.
                  
    newcols[i, 1]     = Q[i, j] * Hrefl[1,1] + Q[i, j+1] * Hrefl[2,1]
    newcols[i, 2]   = Q[i, j] * Hrefl[1,2] + Q[i, j+1] * Hrefl[2,2]
  end
              
  Q[1:j+1, j:j+1] = newcols
\end{lstlisting}

  \subsection{Solving the minimum problem, given QR}
  Given the QR factorization of $\underbar H_n$, we can transform our minimum problem:
  \[\boxed{\min_{z \in \reals^{n+1}} \|\hess_n z - e_1\|y\|\|}
  \text{ \quad into \quad }\boxed{\min_{z \in \reals^{n+1}} \|R_0 z - Q_0^T (e_1 \|y\|)\|}.\]
  \begin{proof} Let $\underbar H_n = QR$, \quad $Q = [Q_0, Q_c]$, \quad $R = [R_0, 0]^T$.
  
  \begingroup
\addtolength{\jot}{.5em}
   \begin{align}
     \|\hess_n z - e_1\|y\|\| &= \|Q^T (\hess_n z - e_1\|y\|)\| \tag{$Q^T$ is norm-preserving}\\
     &= \|Q^TQRz - Q^T( e_1\|y\|)\| \tag{QR factorization of $\underbar H_n$}\\
     &= \left \| \begin{bmatrix}R_0 \\ 0\end{bmatrix} z - \begin{bmatrix}Q_0^T \\ Q_c^T\end{bmatrix} ( e_1\|y\|) \right \| \tag{assumption}\\
     &= \left \|\begin{bmatrix}
         R_0 z - Q_0^T ( e_1\|y\|)\\
         -Q_c^T (e_1\|y\|)
        \end{bmatrix}\right \| \tag{vector algebra}
   \end{align}
   Whose minimum is only influenced by the top portion (the bottom one does not depend on $z$).
\endgroup
  \end{proof}
\noindent Once we have transformed the problem to this form, if $R_0$ is invertible (which is true iff the $\underbar H_n$ is full-rank), we have obtained a \emph{triangular system}, which is efficiently solved by backsubstitution.

\subsection{Computational Complexity}

\subsubsection{Time Complexity of Lanczos+QR}
The algorithm consists of a for-loop of length $n$ (the number of Lanczos iterations). We go through the dominating parts of the $j$-th step of the loop:
\begin{itemize}
 \item The Lanczos iteration's complexity, both in its base and inductive cases, is dominated by the matrix-vector multiplication $w := Aq$, which has time complexity $O(m^2)$ ($m$ is the size of $A$).
 \item The base case of the QR construction consists of a $2\times 2$ QR factorization, which can easily be considered as a constant-time operation.
 \item The inductive case of the QR construction is dominated by the $O(j)$ cost of computing the new columns of the $Q$ and $R$ matrices.
\end{itemize}
This yields a time complexity of
\[O \left(nm + \dfrac{n(n+1)}{2} \right) = O(nm + n^2)\]
Taking in account the fact that we use a sparse matrix data type in the implementation, we can express the time complexity as follows:
\[O(\texttt{nnz(A)} + n^2)\]
\subsubsection{Space Complexity of Lanczos+QR}
Let $\#D$ represent the length of $D$'s diagonal. We need to store:
\begin{itemize}
 \item The matrix (in sparse form): $O(\#D + 2\cdot \texttt{NNZ(E)})$
 \item The Lanczos basis: $O(m \cdot n)$
 \item $Q$ and $R$: $O(n^2)$
\end{itemize}
Hence the space complexity is the sum of the above complexities.

\subsubsection{Time complexity of GMRES}

Our implementation of GMRES consists of:
\begin{itemize}
 \item A Lanczos+QR computation $O(\texttt{nnz(A)} + n^2)$
 \item Solving an $n\times n$ triangular system: $O(n^2)$
\end{itemize}
Hence the complexity is dominated by the Lanczos+QR computation $O(\texttt{nnz(A)} + n^2)$.

\subsubsection{Space complexity of GMRES}
Once again, the space complexity is dominated by that of Lanczos+QR, it is therefore:
\[O(\#D + 2\cdot \texttt{NNZ(E)} + mn + n^2)\]

\subsection{Stability}

As remarked by prof. Poloni in e-mail correspondence, not much can be said about Lanczos's stability. We shall focus on the backward stability of the other two main components of the algorithm, namely QR factorization and backward substitution.

\subsubsection{Background: Backward Stability}

An algorithm is said to be \emph{backward stable} if the computed output $\widetilde y$ can be written as $\widetilde y = f(\widehat x)$, where:
\[ \dfrac{\|\widehat x - x\|}{\|x\|} = O(u) \]
where $\widehat x$ is a perturbed input $x + \Delta x$.

\subsubsection{Backward Stability of QR factorization}

First, we recall the following result:
\begin{theo}[Backward stability of orthogonal transformations] \label{orthobs}
If $Q \in \mathbb R^{m \times m}$ is orthogonal, and $B \in \mathbb R^{m \times n}$, then the computed version $\widetilde C$ of $C = QB$ is backward stable:
\[ \widetilde C = Q\widehat B, \quad\quad \|\widehat B - B\| \leq O(u) \|B\| \]
\end{theo}
\noindent The proof is omitted. We can now prove the following:
\begin{framed}
\begin{claim}
Let $A + \Delta_A$ be a perturbed version of the input matrix $A$. We compute:
\[ \widetilde Q \widetilde R = \texttt{QR}(A + \Delta_A). \]
The computed $\widetilde Q$ and $\widetilde R$ satisfy:
 \[ \widetilde Q \widetilde R = A + \Delta \quad \text{ with  } \quad \|\Delta\| \leq O(u)\|A\|.\]
\end{claim}
\end{framed}

\begin{proof}
 Recall that:
 \[ A_0 = A,\quad\quad A_{k} = Q_k\hdots Q_1 A,
 \quad\quad k \in \{1..n\}\]
Where the $Q_k$s are orthogonal matrices of the form:
\[\begin{bmatrix}
   I & 0\\
   0 & H_k
  \end{bmatrix}
\]
And $H_k$ is a Householder reflector matrix. We first show by induction that:
\[ \widetilde A_k := \widetilde Q_k (\widetilde A_{k-1} + \Delta) \]
is such that $\|\Delta\| \leq O(u)\|A\|$ and $\|\widetilde A_k\| \leq \|A\| + O(u) \|A\|$.
\begin{itemize}
 \item \textbf{Base case}\quad By Theorem \ref{orthobs}:
 \[ \widetilde A_1 = \widetilde Q_1(A + \Delta_1), \quad\quad \|\Delta_1\| = O(u) \|A\|\]
 Additionally:
 \begin{align*}
  \|\widetilde A_1\| &= \|\widetilde Q_1 (A + \Delta_1)\|\\
  &=\|A + \Delta_1\| \tag{orthogonality}\\
  &\leq \|A\| + O(u) \|A\| \tag{prop. of norms, above eqn.}
 \end{align*}

 \item \textbf{Inductive Case} \quad Let us assume:
 \[ \widetilde A_{i} = \widetilde Q_i (\widetilde A_{i-1} + \Delta_i), \quad\quad \|\Delta_i\| \leq O(u)\|A\| \quad\quad \|\tilde A_i\| \leq \|A\| + O(u) \|A\|.\]
 Then:
 \[ \widetilde A_{i+1} = \widetilde Q_{i + 1} (\widetilde A_i  + \Delta_{i+1}) \]
We thus have:
\begin{align*}
  \|\Delta_{i+1}\| &= O(u) \|(\widetilde A_i + \Delta_i)\|\tag{by Theorem \ref{orthobs}}\\
  &\leq O(u) (\|\widetilde A_i\| + \|\Delta_i\|) \tag{prop. of norms}\\
  &= O(u) (\|\widetilde A_i\| + O(u)\|A\|) \tag{Inductive Hp 1}\\
  &\leq O(u) (\|A\| + O(u) \|A\| + O(u) \|A\|) \tag{Inductive Hp 2}\\
  &= \|A\|O(u)
\end{align*}
And finally:
\begin{align*}
 \|\widetilde A_{i+1}\| &= \|\widetilde Q_{i + 1} (\widetilde A_i  + \Delta_{i+1})\|\\
&=   \|\widetilde A_i  + \Delta_{i+1}\| \tag{Orthogonality}\\
  &\leq \|\widetilde A_{i}\| + \|\Delta_{i+1}\| \tag{prop. of norms}\\
  &\leq \|A\| + O(u)\|A\| + \|\Delta_{i+1}\| \tag{Inductive Hp 2}\\
  &\leq \|A\| + O(u)\|A\| + \|A\|O(u) \tag{above inequality}\\
  & = \|A\| + O(u) \|A\|
\end{align*}

\end{itemize}
Now recall that $\tilde R = \tilde A_k$ for some $k$, and therefore, given:
\[ \widetilde Q \widetilde R = A + \Delta \]
we can conclude:
\begin{align*}
 \|\Delta\| &\leq O(u)\|A_k\| \tag{by Theorem \ref{orthobs} }\\
 &\leq O(u) (\|A\| + O(u)\|A\|) \tag{as shown by induction}\\
 &= O(u)\|A\|
\end{align*}

\end{proof}

\section{GMRES with preconditioner}

In this section we discuss how we implemented the algorithm using the following preconditioner: $$P = \begin{bmatrix}
     D & 0\\
     E & S
    \end{bmatrix}$$
    where is $S=ED^{-1}E^T$ or an approximation of it, obtained by replacing the smallest off-diagonal entries of $S$ with zeros. Since our matrix is symmetric, the preconditioned problem we want to solve can be either:
    \[ PAP^T(P^{-T}x) = Py \]
    or
    \[ P^TAP(P^{-1}x) = P^Ty \]
    In our implementation, we provide algorithms to solve both of these systems. As we will later discuss, the second system turned out to provide much more accurate results, but was generally less sparse, hence impacting the compute time.

    \subsection{Implementation details}
    \paragraph{Block computation} In order to save space, we never construct $P$ explicitly. What we do is exploit the block structure to obtain $PAP^T$ and $P^TAP$ directly:
    \[
     PAP^T = \begin{bmatrix}
      D^3 & D^2E^T + DE^TS^T\\
      (ED+SE)D & (ED+SE)E^T + EE^TS^T
     \end{bmatrix}
    \]

    \[
     P^TAP = \begin{bmatrix}
      (D^2+E^TE)D + DE^TE & DE^TS\\
      E^TED & 0
     \end{bmatrix}
    \]
By precomputing the blocks, we obtain a relatively efficient algorithm.
\paragraph{Approximation of $S$} Once $S$ is computed, we can remove all off-diagonal elements under some threshold using the following Julia code:
\begin{lstlisting}
     # set off-diagonal elements under some threshold to zero
    if THRESHOLD_ZERO > 0
        threshold = THRESHOLD_ZERO
        mask = .!I(heightE) .& (abs.(S) .< threshold)
        S[mask] .= 0
    end
\end{lstlisting}

\section{Additional implementations}

\subsection{Restarted versions of the algorithms}

In addition to the GMRES implementation, we provided a \emph{higher-order function} that takes as input any GMRES implementation, and uses it to perform the \textbf{restarted GMRES} algorithm.\bigskip


\paragraph{Reasons for using the restarted version} A common issue with GMRES is that it is a costly computational method that need to keep in memory
 all the vectors of the basis $Q_n$ and the Hessenberg matrix $H_n$ (although, because our matrix is symmetric, we only keep $H_n$'s diagonal and subdiagonal). Additionally, the cost of orthogonalization grows with iterations [\sidenote{\color{red}Check also what are the computational cost}]
 This can be a problem when the matrix $A$ is large thus requiring a large number of iterations to converge to the lucky breakdown.
 Especially when the matrix is ill-conditioned, one way to mitigate those issues is to \emph{restart} the algorithm after a certain number of iterations. The restarted GMRES algorithm is as follows: \newline

 \paragraph{Julia code for the Restarted algorithm}\,
\begin{lstlisting}
function RestartedGMRES(GMRES_Method, A, y, max_iter, restart, tol)

    x = zeros(size(A)[2])

    # Initial guess is initial r0
    r = y - A * x
    norm_r = norm(r)

    iter = 0

    while iter < max_iter && norm_r > tol

      # Perform GMRES and get current solution
      dx = GMRES_Method(A, y, restart)

      x += dx
      r = y - A * x
      norm_r = norm(r)

      iter += restart
    end

    if norm_r > tol
      println("Did not converge")
    end

    return x

\end{lstlisting}

\paragraph{Correctness: restart invariant}
 Let $r_i$ be the residual after restart $i$: $r_i = y-Ax_{i}$. We have the following:
$$Ax_i = y - r_i$$
  $$x' := \texttt{GMRES}(A,r_i) \implies Ax' = \widetilde r_i \approx r_i$$
  Let $x_{i+1} = x_i + x'$, now:
  \[A(x_{i+1}) = Ax_i + Ax' = y - \widetilde r_i + r_i \approx y\]
This shows that, at each restart:
\[A x_i \approx y.\]
Indeed, we should ensure that, under some assumptions, the approximations grow in precision with each iteration, but we do not go into this: with the right parameter choice, we found experimentally that the method provides very good approximations of the solution in very brief time.

\paragraph{Drawbacks of the method}

A well known difficulty with the restarted GMRES algorithm is that it can stagnate when the matrix is not positive definite \cite{saad2003iterative}. Indeed, experimentally, we have noticed that choosing the wrong parameters (\texttt{restart} and tolerance) would yield stagnation. However, as evident from the experimental data, the restarted algorithm often delivered solutions orders of magnitude more fast and precise than the bare implementations.



\section{Generating instances of the problem}

\subsection{Min-Cost Flow}

The problem arises from the KKT system of the convex quadratic separable Min-Cost Flow Problem. The problem is defined as follows:
\begin{itemize}
 \item Let $G = (V, A)$ be a graph, with $V$ its set of nodes, and $A$ its set of arcs.
 \item Let $b \in \mathbb R ^{|V|}$ be a vector of \emph{node flows} (based on which we can classify nodes as source, target or transshipment).
 \item Let $x \in \mathbb R^{|A|}$ be a \emph{flow assignment}:
 \[x = \begin{bmatrix}
    \varphi_1\\
    \vdots\\
    \varphi_{|A|}
   \end{bmatrix}
\]
\item Let $\varphi_{ij}$ be the flow on the edge $(i, j) \in A$.
\item Let $C_{ij} : \reals \to \reals$ be a quadratic function that maps a flow $\varphi$ to the \emph{cost} of transporting such flow through the $(i, j)$ edge.
\end{itemize}

We formulate the problem as follows:
\[ \min \sum_{(i, j) \in E} C_{ij} (\varphi_{ij}) \]
With the constraint given by Kirchhoff's law of conservation of flow:
\[ \forall i \in V . \sum_{\scriptsize \makecell{i \in V\\(j, i) \in A}} \varphi_{i, j} - \sum_{\scriptsize \makecell{i \in V\\(i, j) \in A}} \varphi_{i, j} = b_i.\]
There would be other constraints, e.g. the non-negativity of flows or per-edge upper and lower bounds to the flows, but in order to obtain a KKT system of the requested shape we do not consider these.

\subsection{Problem and constraints in matrix form}
We mentioned that each function $C_{ij}(\varphi)$ is quadratic. Let us write it as:
\[ \forall e \in A \;.\; C_{e} (\varphi) = \dfrac12 c_{e} \varphi^2 + d_{e} \varphi \]
We can thus rewrite the minimum problem as:
\[\min \left ( x^T D x + \langle d, x \rangle \right )
\]
Where:
\[D = \begin{bmatrix}
            c_1 &  & 0\\
             &\ddots & \\
            0  & & c_{|A|}\\
           \end{bmatrix}\quad\quad d =
           \begin{bmatrix}
           d_1\\
           \vdots\\
           d_{|A|}
           \end{bmatrix}
           \]
Additionally, given the incidence matrix $\underline E$, we can write the constraint as simply $\underline E x = b$.
\subsection{KKT System}
From the above problem and equality constraint, we obtain the following system:
\begin{align}
 \underline{E} x &= b \tag{KKT-F}\\
 Dx + \underline{E}^T \cdot \mu &= -d \tag{KKT-G}
\end{align}
With $\mu \in \reals$. The system can be rewritten as:
\[
\begin{bmatrix}
D & \underline E^T\\
\underline E & 0\\
\end{bmatrix}\begin{bmatrix}
x\\ \mu
\end{bmatrix} = \begin{bmatrix}
-d\\b
\end{bmatrix}
\]
In order to obtain an equivalent full-rank system, as suggested in the problem statement, we can remove one row from the incidence matrix.

\subsection{Netgen dataset, and generating $D$}
In order to obtain realistic instances to test our algorithms, we used the netgen \cite{netgenwebsite} dataset. This provides graphs in the DIMACS format defined in \cite{dimacsminflow}, coming with the following information:
\begin{itemize}
 \item Node flow of each vertex
 \item Source, target, capacity, and \emph{linear} cost of each edge.
\end{itemize}
The main issue with this dataset is that, indeed, it only provides linear costs.

\paragraph{Generating $D$} Frangioni et al. \cite{frangioni2011projected} propose a procedure for generating realistic quadratic costs. Their approach is to generate the costs uniformly in $[n, an]$, where $n$ is the size of the matrix, and $a$ is an integer number. The values for $a$ provided in the paper we reference are 10, 20 and 30.
